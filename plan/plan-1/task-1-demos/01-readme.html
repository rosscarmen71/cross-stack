Cross Skills

Claude Code skills that turn a vague request into an approved, verifiable plan by questioning you before anything is built.
The main skill is /cross-plan. It questions you about what you want, shows you demos of the result, then plans how to build it as small, checkable Tasks.
The other skills are the interviews /cross-plan uses, and you can run each one on its own.

Skills

SkillWhat it does
/cross-planTurns a request into an approved plan: what you want, demos of the result, the gap from today's code, how to close it, Tasks, and rules for when things go wrong. Planning only. It never builds anything.
/grill-whatQuestions you about what you want and what "done" means. Never asks how.
/grill-howQuestions you about how an already-defined request should be built, recommending options that fit your project's existing patterns. Never asks what.
/grill-non-negotiablesFinds your non-negotiables and pushes each one until it's specific enough to check.
/grill-what-with-docs/grill-what, plus recording terms in a glossary and decisions in ADRs as you go.
/grill-how-with-docs/grill-how, plus recording terms in a glossary and decisions in ADRs as you go.

Planned (these folders are empty placeholders for now): cross-mode, find-standard, just-show-me, planning-and-verification, research-options, and 12 principle-* skills.

Example

After you approve, your project has:

plan/
├── plan-<id>.md          ← the plan
└── plan-<id>/
    ├── demos/             ← demos of the final result
    ├── task-<n>.md        ← one Sub-plan per Task
    └── task-<n>-demos/    ← that Task's demos

Hand that folder to any executor agent to build.

Install

Claude Code loads skills from ~/.claude/skills/. Link these in (links mean your edits apply immediately):

git clone https://github.com/rosscarmen71/cross-stack.git
cd cross-stack
mkdir -p ~/.claude/skills
for s in cross-plan grill-what grill-what-with-docs grill-how grill-how-with-docs grill-non-negotiables; do
  ln -s "$PWD/skills/$s" ~/.claude/skills/$s
done
ln -s "$PWD/skills/third-party/matt_pocock/domain-modeling" ~/.claude/skills/domain-modeling

Start a new Claude Code session and type /cross-plan.
